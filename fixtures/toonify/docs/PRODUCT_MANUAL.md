# 📄 기획 명세서 및 제품 가이드 (PRODUCT MANUAL)

## 1. 제품 비전

**Toonify**는 스토리텔링 능력은 있지만 그림 실력이 부족한 작가들을 위한 **AI 기반 웹툰 제작 도구**입니다.
자연어 처리(LLM)와 이미지 생성 모델(Image Gen AI)을 결합하여, 텍스트 스크립트를 시각적인 웹툰 컷으로 변환해줍니다.

## 2. 핵심 사용자 (Target User)

- **웹툰 작가 지망생**: 스토리는 있지만 드로잉에 시간이 많이 걸리는 유저.
- **콘텐츠 크리에이터**: 빠르게 숏폼 형태의 웹툰/인스타툰을 제작하고 싶은 유저.

## 3. 주요 기능 (Feature Specs)

### A. 프로젝트 설정 (Project Setup)

- **장르 선택**: 로맨스, 판타지, 스릴러 등 장르에 따라 AI의 톤앤매너가 결정됩니다.
- **세계관 설정 (Worldview)**: 배경 시대, 분위기 등을 프롬프트 형태로 입력받아 전체적인 작품의 배경을 설정합니다.
- **AI 화풍 설정 (Art Style)**:
  - 기본 제공 스타일 (웹툰, 셀화, 수채화, 느와르 등)
  - 사용자 커스텀 스타일 지원 (이미지 업로드 기반 Style Transfer)

### B. 캐릭터 캐스팅 (Character Casting)

- **캐릭터 생성 위자드**: 이름, 나이, 성격(MBTI 등), 외모 묘사를 입력.
- **AI 이미지 생성**: 입력된 정보를 바탕으로 캐릭터의 전신/반신 이미지를 생성.
- **일관성 유지 (Consistency)**: 생성된 캐릭터는 'Seed' 또는 'Reference ID'로 관리되어, 웹툰 컷 생성 시에도 동일한 외모를 유지하도록 설계됨.
- **Retry 기능**: 마음에 들지 않을 경우 재생성 지원.

### C. 디렉터 모드 (Director Mode - Storyboarding)

- **시나리오 작성**: 텍스트로 대본을 작성 (지문, 대사).
- **AI 장면 분석 (Scene Analysis)**: 스크립트를 분석하여 필요한 컷 수와 각 컷의 프롬프트를 자동 생성.
- **컷 편집 (Cut Editor)**:
  - 자동 생성된 프롬프트 수정 가능.
  - 구도(Camera Angle), 조명(Lighting) 등 세부 조정.
- **컷 생성 (Generate)**: 각 컷별로 최종 이미지 생성.

### D. 웹툰 스티칭 & 편집 (Stitching & Layout)

- **세로 스크롤 뷰**: 생성된 컷들을 웹툰 형식(세로 스크롤)으로 자동 배치.
- **말풍선 편집**: 이미지 위에 말풍선(Dialogue Bubble)을 오버레이하여 대사 편집.
- **최종 내보내기**: 이미지 파일 또는 PDF 등으로 추출.

## 4. 사용자 시나리오 (User Journey Map)

1.  **로그인/회원가입**: 이메일 기반 인증.
2.  **대시보드 진입**: 내 프로젝트 목록 확인.
3.  **새 프로젝트 시작**: 마법사(Wizard)를 통해 장르 -> 세계관 -> 스타일 설정.
4.  **캐릭터 생성**: 주인공 및 조연 캐릭터 생성 및 확정.
5.  **에피소드 작성**: 1화 에피소드 생성 -> 스크립트 입력 -> 컷 분할 확인.
6.  **이미지 생성**: 각 컷의 이미지를 생성하고 마음에 드는 컷 선택.
7.  **최종 확인**: 전체적인 흐름을 확인하고 수정.

## 5. 정책 및 제약사항 (Policies)

- **AI 사용량 제한**: 유저 등급에 따라 하루 생성 가능한 이미지 수 제한 (Credit System).
- **콘텐츠 가이드라인**: 선정적, 폭력적인 콘텐츠 생성 시 필터링 적용 (Safety Filter).
