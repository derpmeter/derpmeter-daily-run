# AI 웹툰 생성에서 캐릭터 일관성 문제 해결하기

## 문제 정의

AI 이미지 생성 모델을 활용하여 웹툰 컷을 자동 생성할 때, **컷마다 캐릭터의 의상이 일관되지 않게 변경되는 문제**가 발생합니다.

예를 들어:

- 1컷: 캐릭터가 흰 블라우스를 입고 있음
- 2컷: 같은 캐릭터가 갑자기 파란 후드티를 입고 있음
- 3컷: 또다시 줄무늬 셔츠로 변경됨

이는 독자의 몰입을 방해하고, 웹툰의 전문성과 품질을 크게 저하시킵니다.

## 문제 원인 분석

### 1. AI 이미지 생성의 본질적 특성

생성형 AI 모델은 프롬프트를 기반으로 **매번 새롭게** 이미지를 생성합니다. 이전 컷에서 무엇을 생성했는지 "기억"하지 않기 때문에, 동일한 캐릭터에 대해 매번 다른 해석을 할 수 있습니다.

### 2. 텍스트 프롬프트의 한계

"흰 블라우스를 입은 민지"라고 명시해도, 모델은:

- "흰 블라우스"를 다양한 형태로 해석할 수 있음
- 장면 설명, 대사, 스타일 지시 등 다른 정보와 섞이면서 의상 정보의 우선순위가 낮아짐

### 3. 다중 참조 이미지의 복잡성

여러 캐릭터의 참조 이미지를 개별적으로 전달할 경우:

- 모델이 어떤 캐릭터가 어떤 참조인지 혼동
- 참조 이미지가 많아질수록 각 참조의 영향력 감소

## 가설

> **단일 통합 레퍼런스 보드**를 사용하면, AI 모델이 캐릭터를 더 명확하게 구분하고 일관성 있게 표현할 수 있을 것이다.

### 가설의 근거

1. **시각적 컨텍스트 통합**: 모든 캐릭터를 하나의 이미지에 배치하면, 모델이 전체적인 캐릭터 관계와 구분을 더 잘 이해함

2. **명시적 라벨링**: 빨간색 테두리와 이름 라벨로 각 캐릭터를 시각적으로 구분하면, 모델이 "누가 누구인지"를 명확히 인식

3. **일관된 참조점**: 모든 컷 생성 시 동일한 레퍼런스 보드를 사용하면, 캐릭터 표현의 기준점이 일정하게 유지됨

## 해결 방안: 에피소드 캐릭터 레퍼런스 보드

### 개요

에피소드 시작 전, 해당 에피소드에 등장하는 캐릭터들의 **의상 참조 이미지를 하나의 보드로 합성**하여 캐싱합니다. 이후 모든 컷 생성 시 이 보드를 참조 이미지로 사용합니다.

### 구현 세부사항

#### 1. 레퍼런스 보드 구성

```
┌─────────────────────────────────────────────────┐
│  ┌──────────────┐    ┌──────────────┐           │
│  │              │    │              │           │
│  │  캐릭터 1     │    │  캐릭터 2     │           │
│  │  의상 이미지   │    │  의상 이미지   │           │
│  │              │    │              │           │
│  └──────────────┘    └──────────────┘           │
│      민지              하영                       │
│                                                 │
│  ┌──────────────┐    ┌──────────────┐           │
│  │              │    │              │           │
│  │  캐릭터 3     │    │  캐릭터 4     │           │
│  │  의상 이미지   │    │  의상 이미지   │           │
│  │              │    │              │           │
│  └──────────────┘    └──────────────┘           │
│      지훈              서연                       │
└─────────────────────────────────────────────────┘
```

#### 2. 기술적 사양

| 항목                   | 사양                       | 이유                                         |
| ---------------------- | -------------------------- | -------------------------------------------- |
| **생성 방식**          | PIL (Python Image Library) | 결정론적이고 비용 없음                       |
| **보드당 최대 캐릭터** | 4명                        | 이미지 품질 유지 + 모델 인식 최적화          |
| **다중 보드 지원**     | 4명 초과 시 자동 생성      | 5~8명 → 2개 보드, 9~12명 → 3개 보드          |
| **보드 해상도**        | 2048x2048 이상             | 축소 시 디테일 손실 방지                     |
| **테두리 색상**        | 빨간색 (#FF0000)           | 시각적으로 명확한 구분                       |
| **라벨**               | 캐릭터 이름만              | 텍스트 블리딩 최소화, 상세 설정은 프롬프트로 |

#### 3. 프롬프트 구조

```
[Reference Image] is the CHARACTER REFERENCE BOARD:
- Top-left (민지): Female protagonist, 25 years old, long black hair,
  wearing white blouse and navy skirt
- Top-right (하영): Female friend, short brown hair,
  wearing casual t-shirt and jeans
...

CRITICAL: Each character MUST wear their EXACT outfit as shown in the reference board.
```

#### 4. 워크플로우

```
[에피소드 컷 생성 시작]
        ↓
[에피소드에 등장하는 캐릭터 추출] (character_outfits 기준)
        ↓
[각 캐릭터별 의상 이미지 AI 생성]
   - 기존 프로필 이미지 참조
   - 에피소드 의상 설명 반영
   - 3:4 비율 상반신/전신 이미지
        ↓
[PIL로 레퍼런스 보드 합성]
   - 빨간 테두리 + 이름 라벨
   - 2x2 그리드 (최대 4명/보드)
        ↓
[GCS에 업로드 & URL 캐싱]
        ↓
[모든 컷 생성 시 보드를 참조 이미지로 사용]
```

### 기대 효과

1. **의상 일관성 향상**: 동일한 시각적 참조를 사용하므로 의상 변동 최소화
2. **캐릭터 혼동 감소**: 명확한 라벨링으로 AI가 캐릭터를 정확히 구분
3. **생성 효율 향상**: 레퍼런스 보드 캐싱으로 반복 생성 비용 절감
4. **확장 가능성**: 향후 표정, 포즈 등 다른 일관성 문제에도 적용 가능

## 한계 및 향후 과제

1. **의상 변경 장면**: 극 중 의상이 바뀌는 경우 새로운 보드 생성 필요
2. **텍스트 블리딩 가능성**: 보드의 이름 라벨이 생성 이미지에 나타날 수 있음 (모니터링 필요)

## 결론

AI 이미지 생성에서 캐릭터 일관성은 프롬프트 엔지니어링만으로 해결하기 어려운 근본적인 문제입니다. **시각적 레퍼런스의 통합**과 **명시적 라벨링**을 결합한 레퍼런스 보드 접근법은, 이 문제에 대한 실용적이고 비용 효율적인 해결책을 제시합니다.
