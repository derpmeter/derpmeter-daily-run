# 🚀 Toonify 성장 로드맵 (Post-MVP Roadmap)

> **작성일**: 2025-12-27  
> **최종 업데이트**: 2025-12-27  
> **상태**: 📋 Phase 1 준비 중

## 📋 개요

이 디렉토리는 MVP 이후 Toonify 프로젝트의 성장 전략과 실행 계획을 담고 있습니다. 코드베이스 리팩토링(Phase 1-4)이 완료된 현 시점에서, 수익화와 제품 완성도 향상을 위한 단계별 계획을 정의합니다.

## 📊 현재 상태

| 영역                | 상태           | 비고                  |
| ------------------- | -------------- | --------------------- |
| 코드베이스 리팩토링 | ✅ 완료        | Phase 1-4 모두 완료   |
| AI 엔진             | ⚡ Gemini Only | 단일 프로바이더       |
| 결제 시스템         | 🟡 UI만 구현   | Polar.sh 연동 미완료  |
| 크레딧 시스템       | ✅ 구현        | 차감/리필 로직 동작   |
| 인증 시스템         | ✅ 구현        | Clerk + 커스텀 백엔드 |
| 배포 파이프라인     | ✅ 구현        | GCP Cloud Run         |

## 🎯 3단계 성장 전략

### Phase 1: 수익화 기반 구축 (Monetization Foundation)

> 📄 상세: [phase-1-monetization.md](./phase-1-monetization.md)

- **목표**: 첫 유료 고객 확보, 결제 파이프라인 검증
- **예상 기간**: 2-3주
- **핵심 태스크**:
  - Polar.sh 결제 연동
  - 코인 구매 시스템
  - 구독 요금제 시스템
  - Billing Dashboard

### Phase 2: 제품 완성도 향상 (Product Polish)

> 📄 상세: [phase-2-product-polish.md](./phase-2-product-polish.md)

- **목표**: 유료 고객 100명 달성 전 사용자 경험 최적화
- **예상 기간**: 4-6주
- **핵심 태스크**:
  - 이미지 생성 품질 개선
  - 온보딩 & UX 향상
  - 테스트 커버리지 확대

### Phase 3: 수익성 확보 (Profitability)

> 📄 상세: [phase-3-profitability.md](./phase-3-profitability.md)

- **목표**: 마진율 40% 이상 달성
- **시점**: 유료 구독자 100명 돌파 시
- **핵심 태스크**:
  - Multi-Provider Image Generation (Fal.ai 도입)
  - 캐릭터 일관성 강화
  - 고급 기능 출시
