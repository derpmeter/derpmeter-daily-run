# 📈 Phase 3: 수익성 확보 (Profitability)

> **목표**: 마진율 40% 이상 달성  
> **시작 조건**: 유료 구독자 100명 돌파 시  
> **상태**: 🔮 향후 계획

## 📋 개요

MVP 단계에서는 Gemini 단일 엔진으로 빠르게 시장을 검증합니다. 그러나 Gemini 이미지 생성 원가($0.134/장)가 높아 마진이 거의 없는 상태입니다. 유료 구독자 100명을 돌파하면, Fal.ai(FLUX)를 도입하여 원가를 1/5로 절감하고 본격적인 수익 구조를 확보합니다.

## 💰 수익성 분석

### 현재 (Gemini Only)

```
Pro 플랜 ($39) 기준, 3,000 크레딧 전량 이미지 생성 시:
- 실수령: $36.45 (Polar 수수료 제외)
- AI 원가: $40.20 (300장 × $0.134)
- 손익: -$3.75 (적자)
```

### 목표 (Fal.ai 도입 후)

```
Pro 플랜 ($39) 기준, 동일 사용량:
- 실수령: $36.45
- AI 원가: $6.00~$9.00 (300장 × $0.02~0.03)
- 손익: +$27~$30 (마진율 74~82%)
```

#### 1.1 Fal.ai 연동

| 항목 | 상세                    |

| 모델 | FLUX.1 Pro / FLUX.1 Dev |
| 원가 | $0.02~0.03/장           |
| 품질 | Gemini 대비 동등 이상   |
| 속도 | 3~8초/장                |

**구현 체크리스트**:

- [ ] Fal.ai 계정 생성 및 API 키 발급
- [ ] `backend/app/services/ai/image/fal.py` 생성
- [ ] 이미지 생성 서비스 추상화 레이어
- [ ] Gemini ↔ Fal 프로바이더 선택 로직

#### 1.2 프로바이더 선택 전략

| 용도             | 권장 프로바이더 | 이유              |
| ---------------- | --------------- | ----------------- |
| 패널 이미지      | Fal.ai (FLUX)   | 비용 효율, 고품질 |
| 캐릭터 시트      | Fal.ai (FLUX)   | 일관성 유지       |
| 스타일 샘플      | Gemini          | 멀티모달 참조     |
| 텍스트 기반 작업 | Gemini          | 텍스트 전문       |

#### 1.3 페일오버 로직

```python
# 의사 코드
async def generate_image(prompt, provider="fal"):
    try:
        if provider == "fal":
            return await fal_service.generate(prompt)
    except FalAPIError:
        # Fal 실패 시 Gemini로 폴백
        return await gemini_service.generate(prompt)
```

### 2. 캐릭터 일관성 강화

#### 2.1 현재 한계

- Gemini: 텍스트 프롬프트 기반, 일관성 낮음
- 멀티모달 참조로 개선 시도 중이나 완벽하지 않음

#### 2.2 FLUX 기반 솔루션

| 기술                    | 설명                                |
| ----------------------- | ----------------------------------- |
| **IP-Adapter**          | 참조 이미지 기반 스타일/캐릭터 유지 |
| **LoRA Fine-tuning**    | 캐릭터별 미세 조정 모델             |
| **Character Reference** | FLUX의 캐릭터 일관성 기능           |

**구현 체크리스트**:

- [ ] IP-Adapter 연동 연구
- [ ] 캐릭터 시트를 참조 이미지로 활용
- [ ] A/B 테스트: Gemini vs FLUX 일관성

#### 2.3 마케팅 포인트

```
"완벽한 캐릭터 일관성"
- 같은 캐릭터가 모든 컷에서 동일하게 유지
- Pro/Studio 플랜 차별화 기능
```
